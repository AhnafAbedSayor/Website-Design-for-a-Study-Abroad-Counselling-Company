# Study Abroad Counselling Company Website

A modern, responsive website for a study abroad counselling company, featuring a clean design and essential information for prospective students.

## Features

- **Responsive Design**: Works on all device sizes
- **Multilingual Support**: Language toggle between English and Irish
- **Interactive Elements**: Smooth scrolling and form validation
- **Modern UI**: Clean, professional interface with engaging visuals

## Pages

- **Home**: Overview of services
- **About Us**: Company information and team
- **Services**: Detailed study abroad services
- **Contact**: Get in touch form

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts
